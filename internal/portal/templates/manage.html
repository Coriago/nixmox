Operations

Actions run on the selected node. Installation erases disks described by the target flake's disko configuration. Power and installation controls must be enabled by the administrator.

Add a host · USB installer

  1. Prepare the nixmox x86_64 BIOS/UEFI installer.
  2. Write it to a USB drive attached to {{.Hostname}}.
  3. Boot, install to its internal disk, then join the installed host using discovery.

This writes a bootable live environment, not a permanent installation. For installation to internal disks, use Install / wipe with a disko flake and an image containing your SSH public key.

Checking USB installer support…

Use the public key matching the controller’s SSH identity. Only the public key is embedded in the image.

Cluster rollout

Uses each node's pulled revision. Stops subsequent batches on failure. Use one coordinator; automatic apply should be disabled during rollouts.

Discovered on this network

Discovery is an untrusted hint, not proof of identity. Verify addresses before joining. New hosts can use the cluster setup page to join.

Install / wipe a host

Requires SSH access and a flake with disko, hardware configuration, and nixmox enabled. The installed node joins explicitly after reboot.

Local host inputs

Saved outside Git as inputs.json. Consumed on the next impure NixOS build; saving does not apply configuration.
